What it is

EnAccess Maps is an Enactus Melbourne project aimed at addressing gaps in accessibility infrastructure data. The platform helps people with physical disabilities find, report, and navigate accessible routes and facilities — information that's often fragmented, outdated, or missing from mainstream mapping products.

I joined as part of the software developer team in August 2026. The project is in active development across both a web platform and a companion mobile app.

Features I've implemented

01

Google Maps API integration

Wired up the Google Maps JavaScript API to render live, interactive maps with accessibility-specific data overlays. Handles map initialisation, event listeners, and marker management.

02

Accessibility marker layer

Built a custom marker layer that plots accessibility points of interest — ramps, lifts, accessible entrances — pulled from the project's data source and rendered on the map in real time.

03

React UI components

Designed and built reusable React components for the web platform front-end, including the map container, filter controls, and location detail panels.

04

Python feature development

Contributed Python-side features to the platform's back-end, including data processing pipelines that clean and structure accessibility data before it's served to the front-end.

05

Mobile app contributions (in progress)

Actively contributing to the early development phase of the companion mobile app — scoping new feature ideas, prototyping UI flows, and expanding the project's accessibility coverage.
